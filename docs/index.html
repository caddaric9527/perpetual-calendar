怎么订阅

订阅后自动刷新，无需每年重新导入

📱 iPhone / iPad

  1. 点上面的「订阅」按钮（或复制 webcal:// 链接在 Safari 打开）
  2. 弹出「订阅日历」后点 订阅
  3. 也可手动：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历

💻 Mac / Outlook

  1. Mac 日历 App：文件 → 新建日历订阅，粘贴 https:// 链接
  2. 刷新频率选「每天」，勾选「忽略提醒」
  3. Outlook：添加日历 → 从 Internet 订阅
